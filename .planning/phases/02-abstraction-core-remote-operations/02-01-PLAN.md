    function permToRwx(perm) {
      const r = perm & 4 ? 'r' : '-';
      const w = perm & 2 ? 'w' : '-';
      const x = perm & 1 ? 'x' : '-';
      return r + w + x;
    }

    Copy the `getFileTree` logic from index.js lines 2446-2520 as the `listFiles` method body. Must produce identical output shape: `{ name, path, type, size, modified, permissions, permissionsRwx, children }`. Same skip patterns: `node_modules`, `dist`, `build`, `.git`, `.svn`, `.hg`. Same sorting: directories first, then alphabetical.

    Export `const localOperations` object implementing all ProjectOperations methods:

    - `async listFiles(dirPath, options = {})`: Replicates getFileTree. `options.maxDepth` defaults to 3, `options.showHidden` defaults to true. Recursive readdir + stat with depth tracking. Skip patterns identical to getFileTree.

    - `async readFile(filePath)`: `return fsPromises.readFile(filePath, 'utf8')`

    - `async readFileBinary(filePath)`: `return fsPromises.readFile(filePath)` (returns Buffer)

    - `async writeFile(filePath, content)`: `await fsPromises.writeFile(filePath, content, 'utf8')`

    - `async createItem(parentPath, name, type)`: For 'directory': `fsPromises.mkdir(resolvedPath, { recursive: false })`. For 'file': ensure parent exists via `fsPromises.mkdir(parentDir, { recursive: true })` then `fsPromises.writeFile(resolvedPath, '', 'utf8')`. resolvedPath = `path.join(parentPath, name)`. Return `{ path: resolvedPath, name, type }`.

    - `async renameItem(oldPath, newName)`: `const newPath = path.join(path.dirname(oldPath), newName); await fsPromises.rename(oldPath, newPath); return { oldPath, newPath, newName }`.

    - `async deleteItem(targetPath)`: `const stats = await fsPromises.stat(targetPath); if (stats.isDirectory()) await fsPromises.rm(targetPath, { recursive: true, force: true }); else await fsPromises.unlink(targetPath);`

    - `async stat(targetPath)`: Call `fsPromises.stat(targetPath)`, return `{ size: stats.size, modified: stats.mtime.toISOString(), type: stats.isDirectory() ? 'directory' : 'file', permissions: octalString, permissionsRwx: rwxString }` using the same permission formatting as getFileTree.

    - `async exists(targetPath)`: `try { await fsPromises.access(targetPath); return true; } catch { return false; }`

    - `async spawnShell(options)`: Use `pty.spawn` matching the pattern from server/index.js lines 1734-1790. Detect shell: `options.shell || process.env.SHELL || '/bin/bash'`. Spawn: `const proc = pty.spawn(shell, [], { name: 'xterm-256color', cols: options.cols || 80, rows: options.rows || 24, cwd: options.cwd || process.env.HOME, env: { ...process.env, ...options.env, COLORTERM: 'truecolor', FORCE_COLOR: '3' } })`. Return ShellSession: `{ write(data) { proc.write(data); }, resize(cols, rows) { proc.resize(cols, rows); }, onData(handler) { proc.onData(handler); }, onExit(handler) { proc.onExit(handler); }, kill() { proc.kill(); }, pid: proc.pid }`.

    Use module JSDoc: `@module remote/local-operations`.
