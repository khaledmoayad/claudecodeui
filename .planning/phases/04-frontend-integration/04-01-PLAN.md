  <action>
    **Server endpoints** -- Add two routes inside `createRemoteConnectionRoutes()` in `server/routes/remote-connections.js`, before the `return router;` line:

    1. `GET /:id/browse` -- Browse remote filesystem for directory picker
       - Requires active connection (`getConnection(req.params.id)`)
       - Gets `path` from query string (default to `/` if missing)
       - Calls `mgr.transport.request('fs/readdir', { path, maxDepth: 1 })` to get directory listing
       - Filters results to directories only (`entry.type === 'directory'`)
       - Returns `{ path, entries: [{ name, path, type }] }`
       - On error: 400 if no path, 404 if host not found, 409 if not connected, 500 on RPC error

    2. `POST /:id/add-project` -- Register a remote project
       - Reads `{ remotePath }` from request body
       - Validates `remotePath` is a non-empty string
       - Imports `addProjectManually` from `../../projects.js` (dynamic import at top of file or inside handler)
       - Computes project name: `remote:${req.params.id}:${Buffer.from(remotePath).toString('base64')}`
       - Extracts display name from remotePath: last path segment (e.g., `/home/user/myproject` -> `myproject`)
       - Calls `addProjectManually(projectName, displayName)` wrapped in try/catch
       - IMPORTANT: `addProjectManually` calls `fs.access(absolutePath)` which will fail for remote paths. The handler must catch this and instead directly manipulate the project config:
         - Import `loadProjectConfig` and `saveProjectConfig` from `../../projects.js`
         - Check if project already exists in config, return existing if so
         - Add `{ manuallyAdded: true, originalPath: remotePath, isRemote: true, hostId: req.params.id }` to config
         - Save config
         - Return `{ success: true, project: { name: projectName, displayName, remotePath, hostId } }`
       - On error: 400 if missing remotePath, 404 if host not found, 500 on save error
