**Module-level utility -- `calculateBackoff(attempt)`:**
```javascript
function calculateBackoff(attempt) {
  const exponential = Math.min(BASE_BACKOFF_MS * Math.pow(2, attempt), MAX_BACKOFF_MS);
  const jitter = Math.random() * JITTER_MS;
  return exponential + jitter;
}
```

**Module-level utility -- `sshRunCommand(client, command)`:**
This wraps the ssh2 Client's remote command execution API (NOT child_process -- this runs commands on the REMOTE host over SSH). Returns a Promise.
```javascript
function sshRunCommand(client, command) {
  return new Promise((resolve, reject) => {
    client.exec(command, { env: { TERM: 'dumb' } }, (err, channel) => {
      if (err) return reject(err);
      let stdout = '';
      let stderr = '';
      channel.on('data', (d) => { stdout += d.toString(); });
      channel.stderr.on('data', (d) => { stderr += d.toString(); });
      channel.on('close', (code) => resolve({ stdout, stderr, code }));
    });
  });
}
```

**Export class `SSHConnectionManager extends EventEmitter`:**

Constructor(`hostConfig`):
- `hostConfig` has: id, hostname, port, username, privateKeyPath, name
- `this._hostConfig = hostConfig`
- `this._state = CONNECTION_STATES.DISCONNECTED`
- `this._client = null` (ssh2 Client instance)
- `this._transport = null` (SSHTransport instance)
- `this._reconnectAttempt = 0`
- `this._reconnectTimer = null`
- `this._intentionalDisconnect = false`

Property getters:
- `get state()` returns `this._state`
- `get transport()` returns `this._transport`
- `get hostId()` returns `this._hostConfig.id`
- `get isReady()` returns `this._state === CONNECTION_STATES.READY`

`_setState(newState, detail = null)`:
- Store old state, set new state
- Emit `'state'` event with `{ state: newState, previousState: oldState, detail }`
- Log: `console.log('[ConnectionManager:' + this._hostConfig.name + '] ' + oldState + ' -> ' + newState + (detail ? ' (' + detail + ')' : ''))`

`async connect()`:
- If state is CONNECTING, DEPLOYING, or INITIALIZING, return (already in progress)
- Set `this._intentionalDisconnect = false`
- Reset `this._reconnectAttempt = 0`
- Call `this._doConnect()`

`async _doConnect()`:
1. Set state to CONNECTING
2. Read private key file. On error (ENOENT, EACCES), set state to ERROR with detail, return.
3. Create `this._client = new Client()`
4. CRITICAL: Attach error handler BEFORE calling connect():
   `this._client.on('error', (err) => this._handleSSHError(err))`
5. Await SSH ready via Promise:
   - `this._client.once('ready', resolve)` and `this._client.once('error', reject)`
   - Call `this._client.connect({ host, port: port || 22, username, privateKey, keepaliveInterval: SSH_KEEPALIVE_INTERVAL_MS, keepaliveCountMax: SSH_KEEPALIVE_COUNT_MAX, readyTimeout: SSH_READY_TIMEOUT_MS })`
   - On rejection, call `this._handleConnectionFailure(err.message)`, return
6. After ready, remove one-time listeners and attach persistent ones:
   - `this._client.removeAllListeners('error')`
   - `this._client.on('error', (err) => this._handleSSHError(err))`
   - `this._client.on('close', () => this._handleSSHClose())`
   - `this._client.on('end', () => this._handleSSHClose())`
7. DEPLOYING: Set state. Kill existing daemon via sshRunCommand: `'kill $(cat ~/' + DAEMON_PID_PATH + ' 2>/dev/null) 2>/dev/null; rm -f ~/' + DAEMON_PID_PATH` (catch and ignore errors -- no existing daemon is fine). Call `deployDaemon(this._client)`. If deployed, update DB via `remoteHostsDb.updateDaemonVersion(hostConfig.id, result.version)` (wrapped in try/catch).
8. INITIALIZING: Set state. Launch daemon via sshRunCommand-like pattern but keep the channel open: `this._client.exec('node ~/' + DAEMON_REMOTE_PATH, { env: { TERM: 'dumb' } }, callback)`. Create `this._transport = new SSHTransport(channel)`. Send initialize handshake: `const initResult = await this._transport.request('initialize', { protocolVersion: PROTOCOL_VERSION, clientVersion: '1.0.0' }, DAEMON_READY_TIMEOUT_MS)`. If `initResult.protocolVersion !== PROTOCOL_VERSION`, re-deploy with `{ force: true }`, close transport, restart daemon, retry handshake once. If still mismatched, set ERROR state.
9. READY: Reset reconnect attempts to 0. Set state to READY.
10. Wrap steps 7-9 in try/catch. On error: `this._handleConnectionFailure(err.message)`

`disconnect()`:
- Set `this._intentionalDisconnect = true`
- Clear reconnect timer if set
- Close transport if exists, set to null
- End ssh client if exists (try/catch), set to null
- Set state to DISCONNECTED

`_handleSSHError(err)`:
- Log error
- If intentional disconnect, return
- Call `_attemptReconnect(err.message)`

`_handleSSHClose()`:
- If intentional disconnect or already DISCONNECTED, return
- Clean up transport (close if exists, null it)
- Call `_attemptReconnect('SSH connection closed')`

`_handleConnectionFailure(reason)`:
- Close transport if exists, null it
- Destroy client if exists, null it
- Call `_attemptReconnect(reason)`

`_attemptReconnect(reason)`:
- Increment `this._reconnectAttempt`
- If > MAX_RECONNECT_ATTEMPTS: set state to FAILED with detail, return
- Set state to RECONNECTING with detail showing attempt number and reason
- Calculate delay via `calculateBackoff(this._reconnectAttempt - 1)`
- Log delay and attempt number
- Set `this._reconnectTimer = setTimeout(() => this._doConnect(), delay)`

`destroy()`:
- Call `disconnect()`
- Call `this.removeAllListeners()`

**Static method `testConnection(config)`:**
Quick SSH connectivity test without full lifecycle. Creates temporary ssh2 Client, connects, optionally checks node version, disconnects.
- Read private key from `config.privateKeyPath`. On error return `{ success: false, error: 'Cannot read key file: ...' }`
- Create Client, set timeout of SSH_READY_TIMEOUT_MS
- On ready: try running `node --version` on remote via ssh2 remote command execution (same pattern as sshRunCommand). End client. Return `{ success: true, nodeVersion }`.
- On error: destroy client, return `{ success: false, error: err.message }`
- On timeout: destroy client, return `{ success: false, error: 'Connection timed out' }`
