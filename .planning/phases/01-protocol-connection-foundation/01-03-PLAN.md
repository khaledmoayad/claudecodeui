Create `server/remote/transport.js` -- the server-side JSON-RPC transport that communicates with the ccud daemon over an SSH channel. This is the MOST CRITICAL protocol layer. It must use a proper remainder-buffer line parser. Never parse per-chunk.

Module-level JSDoc: `/** @module remote/transport */`

Import:
- `import { RPC_DEFAULT_TIMEOUT_MS, MAX_MESSAGE_SIZE_BYTES } from '../constants/remote.js';`

Export the `SSHTransport` class with these members:

**Constructor `SSHTransport(channel)`:**
- `this._channel` = the ssh2 channel (has stdin/stdout streams accessible via the channel itself acting as a duplex stream, OR via channel.stdout if it's an exec channel -- handle both patterns)
- `this._buffer` = '' (remainder buffer for line parsing)
- `this._pendingRequests` = new Map() -- maps JSON-RPC id -> { resolve, reject, timer }
- `this._notificationHandlers` = [] -- array of callback functions for notifications
- `this._nextId` = 1 -- incrementing request ID counter
- `this._closed` = false
- Determine the readable stream: if `channel.stdout` exists use that, otherwise use `channel` itself as the readable
- Determine the writable: if `channel.stdin` exists use `channel.stdin`, otherwise use `channel` itself
- Store as `this._readable` and `this._writable`
- Attach `this._readable.on('data', (chunk) => this._onData(chunk))` for incoming data
- Attach `channel.stderr.on('data', (chunk) => { console.error('[ccud:remote]', chunk.toString().trimEnd()); })` for daemon stderr
- Attach `channel.on('close', () => this._onClose())` for channel close
- Attach `channel.on('error', (err) => this._onError(err))` for channel errors

**`_onData(chunk)` method:**
- Append `chunk.toString('utf8')` to `this._buffer`
- Check buffer size: if `this._buffer.length > MAX_MESSAGE_SIZE_BYTES`, log error via console.error and clear buffer (set to '')
- Call `this._processBuffer()`

**`_processBuffer()` method -- CRITICAL: remainder-buffer line parser:**
- `const lines = this._buffer.split('\n');`
- `this._buffer = lines.pop();` -- keep incomplete last line as remainder
- For each complete line in `lines`: if empty after trim(), skip. Otherwise try `JSON.parse(line)` and call `this._dispatch(parsed)`
- On JSON parse error: `console.error('[SSHTransport] Invalid JSON:', e.message)`

**`_dispatch(msg)` method:**
- If `msg.id !== undefined` AND `this._pendingRequests.has(msg.id)`:
  - Get pending entry, clear its timer via clearTimeout, delete from map
  - If `msg.error`: `pending.reject(new Error(msg.error.message || 'RPC error'))`
  - Else: `pending.resolve(msg.result)`
- Else if `msg.method` AND `msg.id === undefined` (notification from daemon):
  - Call each handler in `this._notificationHandlers` with `msg`
- Else:
  - `console.error('[SSHTransport] Unhandled message:', JSON.stringify(msg))`

**`request(method, params, timeoutMs)` method (returns Promise):**
- If `this._closed`, return `Promise.reject(new Error('Transport closed'))`
- `const id = this._nextId++`
- Create JSON-RPC request: `{ jsonrpc: '2.0', id, method, params: params || {} }`
- Return new Promise: store `{ resolve, reject, timer }` in `this._pendingRequests`
  - `timer` = setTimeout that rejects with `new Error('RPC timeout: ' + method)` and deletes from map
  - Timeout = `timeoutMs || RPC_DEFAULT_TIMEOUT_MS`
- Write to writable: `this._writable.write(JSON.stringify(request) + '\n')`

**`notify(method, params)` method:**
- If `this._closed` return
- Create notification: `{ jsonrpc: '2.0', method, params: params || {} }` (no id field)
- Write: `this._writable.write(JSON.stringify(notification) + '\n')`

**`onNotification(handler)` method:**
- Push handler to `this._notificationHandlers`
- Return a cleanup function: `() => { const idx = this._notificationHandlers.indexOf(handler); if (idx !== -1) this._notificationHandlers.splice(idx, 1); }`

**`_onClose()` method:**
- If already `this._closed`, return (prevent double cleanup)
- `this._closed = true`
- For each entry in `this._pendingRequests`: clearTimeout(entry.timer), entry.reject(new Error('Transport closed'))
- Clear `this._pendingRequests`

**`_onError(err)` method:**
- `console.error('[SSHTransport] Channel error:', err.message)`
- Call `this._onClose()`

**`close()` method:**
- Call `this._onClose()`
- Try `this._channel.close()` in try/catch (may already be closed)

**`get isClosed()` getter:**
- Return `this._closed`

Module-level JSDoc: `/** @module remote/deployer */`

- `import { fileURLToPath } from 'url';`
- `import { dirname } from 'path';`

Resolve local paths:
```javascript
const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);
const LOCAL_DAEMON_PATH = resolve(__dirname, '../../dist/ccud.mjs');
const CCUD_PKG_PATH = resolve(__dirname, '../../ccud/package.json');
```

**Helper `function sshExec(sshClient, command, options = {})`:**
NOTE: This uses ssh2's `sshClient.exec()` API which executes commands on the REMOTE host over SSH. This is NOT the Node.js `child_process.exec` function. ssh2's exec API is the only way to run commands on remote servers.
- Returns a Promise wrapping `sshClient.exec(command, { env: { TERM: 'dumb', ...options.env } }, callback)`
- In the callback, if error, reject
- Otherwise collect channel stdout data chunks into a string, collect stderr into a string
- On channel `close` event with exit code, resolve with `{ stdout, stderr, code }`

**Export `async function checkRemoteNodeVersion(sshClient)`:**
- Call `sshExec(sshClient, 'node --version')`
- Parse stdout: extract version string (e.g., `v22.0.0`), parse major version via `parseInt(stdout.trim().replace('v', '').split('.')[0], 10)`
- If command failed (code !== 0) or major is NaN: return `{ ok: false, version: null, error: 'Node.js not found on remote host. Install Node.js 20+ to use remote projects.' }`
- If major < 20: return `{ ok: false, version: stdout.trim(), error: 'Node.js 20+ required on remote host, found: ' + stdout.trim() }`
- On success: return `{ ok: true, version: stdout.trim() }`

**Export `async function getLocalDaemonVersion()`:**
- `const raw = await readFile(CCUD_PKG_PATH, 'utf8');`
- `const pkg = JSON.parse(raw);`
- Return `pkg.version`
- If read fails, throw: `new Error('ccud/package.json not found. Run npm run build:daemon first.')`

**Export `async function getRemoteDaemonVersion(sshClient)`:**
- Call `sshExec(sshClient, 'cat ~/.ccud/daemon-version 2>/dev/null || echo ""')`
- Return `result.stdout.trim() || null`

**Export `async function deployDaemon(sshClient, options = {})`:**
- `options.force` = boolean, skip version check

Steps:
1. Verify local daemon exists: `await stat(LOCAL_DAEMON_PATH)`. On ENOENT throw `new Error('dist/ccud.mjs not found. Run npm run build:daemon first.')`
2. Get local version: `const localVersion = await getLocalDaemonVersion()`
3. Unless `options.force`:
   - Get remote version: `const remoteVersion = await getRemoteDaemonVersion(sshClient)`
   - If `remoteVersion === localVersion`: return `{ deployed: false, version: localVersion, reason: 'up-to-date' }`
4. Check Node.js: `const nodeCheck = await checkRemoteNodeVersion(sshClient)`. If `!nodeCheck.ok` throw `new Error(nodeCheck.error)`
5. Create remote directory: `await sshExec(sshClient, 'mkdir -p ~/' + DAEMON_REMOTE_DIR)`
6. Open SFTP: wrap `sshClient.sftp()` in Promise -- callback `(err, sftp)` pattern. If err, throw.
7. Upload to staging: wrap `sftp.fastPut(LOCAL_DAEMON_PATH, DAEMON_REMOTE_DIR + '/.ccud-staging.mjs', callback)` in Promise. Use the home-relative path properly by resolving with `~/` prefix removed (SFTP paths are typically absolute). Instead, use `sshExec` to get home dir first: `const homeResult = await sshExec(sshClient, 'echo $HOME')`, then use `homeResult.stdout.trim()` as base.
   - Actually, the simpler approach: use `sftp.fastPut(LOCAL_DAEMON_PATH, remoteHome + '/' + DAEMON_REMOTE_DIR + '/.ccud-staging.mjs')`
   - Get `remoteHome` via `sshExec(sshClient, 'echo $HOME')` at start of function
8. Get local size: `const localStat = await stat(LOCAL_DAEMON_PATH)`, `localStat.size`
9. Atomic rename + chmod: `await sshExec(sshClient, 'mv ~/' + DAEMON_REMOTE_DIR + '/.ccud-staging.mjs ~/' + DAEMON_REMOTE_PATH + ' && chmod +x ~/' + DAEMON_REMOTE_PATH)`
10. Verify size: `const sizeResult = await sshExec(sshClient, 'stat -c%s ~/' + DAEMON_REMOTE_PATH + ' 2>/dev/null || stat -f%z ~/' + DAEMON_REMOTE_PATH)`. Parse stdout as integer. If differs from localStat.size, log warning via `console.warn('[Deployer] Size mismatch: local=' + localStat.size + ' remote=' + remoteSize)` but don't fail.
11. Write version marker: `await sshExec(sshClient, "echo '" + localVersion + "' > ~/" + DAEMON_REMOTE_DIR + '/daemon-version')`
12. End SFTP: `sftp.end()`
13. Return `{ deployed: true, version: localVersion, reason: options.force ? 'forced' : 'version-mismatch' }`
