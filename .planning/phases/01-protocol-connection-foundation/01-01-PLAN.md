1. Create `server/routes/remote-hosts.js` as an Express router module. Follow the exact pattern from `server/routes/projects.js`:
   - Module-level JSDoc: `/** @module routes/remote-hosts */`
   - `import express from 'express';`
   - `import { Client } from 'ssh2';`
   - `import { readFile } from 'fs/promises';`
   - `import { remoteHostsDb } from '../remote/remote-hosts-db.js';`
   - `import { SSH_READY_TIMEOUT_MS } from '../constants/remote.js';`
   - `const router = express.Router();`
   - `export default router;`

   Implement these routes:

   **POST /** (Create host):
   - Extract `{ name, hostname, port, username, privateKeyPath }` from `req.body`
   - Validate: `name` required (string, 1-100 chars), `hostname` required (string, non-empty), `username` required (string, non-empty), `privateKeyPath` required (string, non-empty)
   - `port` defaults to 22, must be integer 1-65535 if provided
   - Call `remoteHostsDb.create(...)`, return 201 with the created host object
   - On validation error: 400 with `{ error: 'description' }`
   - On DB error: 500 with `{ error: 'Failed to create remote host' }`

   **GET /** (List all hosts):
   - Call `remoteHostsDb.getAll()`, return 200 with array

   **GET /:id** (Get single host):
   - Call `remoteHostsDb.getById(req.params.id)`
   - If not found: 404 with `{ error: 'Remote host not found' }`
   - Return 200 with host object

   **PUT /:id** (Update host):
   - Same validation as POST
   - Check host exists first (404 if not)
   - Call `remoteHostsDb.update(...)`, return 200 with updated host

   **DELETE /:id** (Delete host):
   - Call `remoteHostsDb.delete(req.params.id)`
   - If no changes (not found): 404 with `{ error: 'Remote host not found' }`
   - Return 200 with `{ success: true }`

   **POST /test** (Test connectivity with config in body, pre-save):
   - Extract `{ hostname, port, username, privateKeyPath }` from `req.body`
   - Validate hostname, username, privateKeyPath required
   - Read private key file with `readFile(privateKeyPath)` -- catch ENOENT and return `{ success: false, error: 'Cannot read key file: ...' }`
   - Create `new Client()` from ssh2
   - Set a timeout of `SSH_READY_TIMEOUT_MS` (20s)
   - Attach `.once('ready', ...)` handler: clearTimeout, `client.end()`, resolve `{ success: true }`
   - Attach `.once('error', ...)` handler: clearTimeout, `client.destroy()`, resolve `{ success: false, error: err.message }`
   - Call `client.connect({ host: hostname, port: port || 22, username, privateKey, readyTimeout: SSH_READY_TIMEOUT_MS })`
   - On timeout: `client.destroy()`, resolve `{ success: false, error: 'Connection timed out' }`
   - Return 200 with the result object (always 200, success/failure is in the response body)

   **POST /:id/test** (Test connectivity for saved host):
   - Look up host by id (404 if not found)
   - Use the same connectivity test logic as POST /test, but with the saved host's config
   - Return 200 with result

   All routes wrapped in try/catch with `res.status(500).json({ error: '...' })` pattern.
